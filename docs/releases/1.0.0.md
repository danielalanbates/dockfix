First release of DockFix: repairs Dock icons that turn into "?" and stops it happening for apps on external drives.

- **Automatic fix:** when a drive that holds Dock apps mounts after the Dock started, DockFix restarts the Dock once (about 5 seconds later). A tiny background check runs at login and on each mount, then exits.
- **Menu bar icon** that changes when a Dock item is broken, with one-click **Repair** for moved apps, Restart Dock, and Clear Icon Cache.
- **Window** listing every Dock item with its status, and an Undo for the last repaired item (other items untouched).
- Command line: `DockFix.app/Contents/MacOS/DockFix --help`.

Install: unzip, move DockFix.app to /Applications, open it, and turn on both switches. Requires macOS 13+, universal (Apple silicon and Intel). Signed with Developer ID.
